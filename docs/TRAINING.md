# Learning to See — technical replica (pix2pix / ocean)

A replica of the **"Learning to See"** architecture by Memo Akten: a pix2pix trained on
**a single domain** of images (here: ocean/waves), where the training pair is not two
different images, but **the same image and its edge map**:

```
A (input)  = cv2.Canny(image)       ← what the model "sees"
B (target) = the real image         ← what the model "imagines"
```

At inference time, any edge input (a webcam, a rag, a hand) is translated into the only
domain the model knows. That is the conceptual point of the piece.

Codebase: [junyanz/pytorch-CycleGAN-and-pix2pix](https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix)
(the modern equivalent of the TF1 `affinelayer/pix2pix-tensorflow` that Akten used).
Preprocessing pattern taken from [memoakten/webcam-pix2pix-tensorflow](https://github.com/memoakten/webcam-pix2pix-tensorflow)
and [joshmurr/cci-auto-pix2pix](https://github.com/joshmurr/cci-auto-pix2pix).

## 1. Environment

Already created in `.venv` (Python 3.11, torch CPU + OpenCV). To activate it:

```powershell
.\.venv\Scripts\Activate.ps1      # PowerShell
```
```bash
source .venv/Scripts/activate     # Git Bash
```

Recreate it from scratch:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
```

## 2. Validate the raw images

```powershell
python check_dataset.py
```

Reports how many images are readable and their resolutions, and warns about broken files,
images that are too small, or grayscale images. `--delete_broken` removes the broken ones.

## 3. Generate the A|B pairs

First, calibrate the Canny thresholds on a few images:

```powershell
python preprocess_canny.py --preview 8 --t1 100 --t2 200
```

Look at `./data/preview`: the edges should capture the structure of the waves without
turning into noise. For water, smoothing before Canny usually helps (as in Akten's webcam-pix2pix):

```powershell
python preprocess_canny.py --preview 8 --t1 60 --t2 180 --pre_blur 3 --pre_median 3
```

When the result looks right, process everything:

```powershell
python preprocess_canny.py --t1 60 --t2 180 --pre_blur 3 --pre_median 3 --val_frac 0.05
```

Output: `./data/AB/train/*.png`, each one **512x256** = `[A(256) | B(256)]`.

Main options:

| Flag | What it does |
|---|---|
| `--t1 / --t2` | low/high thresholds of `cv2.Canny` |
| `--pre_blur N` | `GaussianBlur` with kernel N (odd) before Canny |
| `--pre_median N` | `medianBlur` with kernel N (odd) before Canny |
| `--aperture` | Canny Sobel kernel (3/5/7) |
| `--invert` | black edges on white |
| `--size` | side of the square (default 256; the pair comes out 2·size × size) |
| `--val_frac` | fraction diverted to `data/AB/val` |
| `--preview N` | processes only N images into `data/preview` |
| `--overwrite` | reprocesses already existing pairs |

Images are **stretched** to 256x256 without preserving the aspect ratio, as in Akten's
original pipeline.

## 4. Training (Google Colab, GPU)

Upload `data/AB` and the repo to Colab, and from `pix2pix/`:

```bash
python train.py --dataroot ./data/AB --name ocean_learning_to_see \
  --model pix2pix --direction AtoB --dataset_mode aligned
```

Useful flags on Colab:

```bash
  --n_epochs 100 --n_epochs_decay 100   # 200 epochs in total (default)
  --batch_size 4                        # raise if the GPU allows it
  --display_id -1                       # disables visdom (no server on Colab)
  --save_epoch_freq 20                  # periodic checkpoints in case the session is cut
  --continue_train --epoch_count N      # resume after a disconnection
```

Checkpoints end up in `pix2pix/checkpoints/ocean_learning_to_see/`.

## 5. Test / inference

```bash
python test.py --dataroot ./data/AB --name ocean_learning_to_see \
  --model pix2pix --direction AtoB --dataset_mode aligned --num_test 50
```

Results in `pix2pix/results/ocean_learning_to_see/test_latest/index.html`.

To run inference on arbitrary edges (the "real" use of the piece), generate A|B pairs with
`preprocess_canny.py` from your new images into `data/AB/test` and use
`--dataroot ./data/AB --phase test`. The B side is ignored during generation; it is only used as a
visual reference in the results HTML.

## Notes

- `visdom` is not in `requirements.txt`: its installation fails on Windows with modern
  setuptools and the repo no longer lists it. Use `--display_id -1`, or `--use_wandb` for logging.
- The cloned repo uses `environment.yml` (conda) instead of `requirements.txt`; the
  root `requirements.txt` is the pip equivalent of those dependencies plus OpenCV.
- `data/` and `checkpoints/` are in `.gitignore`.
